# MyCityLofts

Site vitrine de la marque MyCityLofts, en anglais avec versions française et portugaise.

- Tout le site tient dans `index.html` (textes, traductions, images intégrées).
- Hébergement : GitHub Pages (Settings → Pages → branche `main`, dossier `/`).
- Formulaire de contact : envoyé par FormSubmit vers l'adresse définie dans `FORM_ID` en haut du script.
  Au premier envoi, FormSubmit envoie un e-mail d'activation : il faut cliquer sur le lien.
  Ensuite, remplacer l'adresse dans `FORM_ID` par l'identifiant aléatoire fourni par FormSubmit, pour ne plus afficher l'e-mail dans le code.
